# Al Tiro · identidad Sidarta

Esta actualización incluye cinco estilos de vehículo seleccionables (compacto, sedán, SUV, pickup y moto), guía ilustrada de hologramas, una barra flotante con símbolos propios y encabezados con la identidad del conductor.

La bienvenida pide el nombre y abre un tutorial interactivo con navegación real y calendario de ejemplo. Puede omitirse y repetirse desde Ajustes; el vehículo de demostración no se guarda. El calendario incorpora bloques naranja para restricciones, días de revisión diferenciados, resumen mensual y detalle por fecha.

La app sustituye el ajolote por una persona amigable al volante, conservando las formas redondeadas, los ojos con brillo y el timón con carretera central del símbolo anterior. Toda la interfaz adopta naranja, ámbar, carbón y blanco a partir de la referencia Sidarta.

- Logo humano y carro generados, optimizados como PNG con transparencia; maestros y prompts incluidos en el código fuente.
- Temas claro y oscuro actualizados en inicio, calendario, autos, alertas, formularios y ajustes. Íconos renovados para Android, web y Windows.
- Texto carbón sobre botones naranja y tonos más oscuros para texto sobre fondos claros. Combinaciones principales verificadas con contraste superior a 4.5:1.
- Se conservan español/inglés, datos guardados y el comportamiento de reglas y API de la versión anterior.

Validación: Flutter analyze sin incidencias y 37 pruebas superadas. Compilaciones web y Android release; inspección visual de ambos temas en navegador.

## Alcance preliminar

La API en vivo y la revisión normativa completa siguen pendientes. Sin avisos oficiales vigentes confirmados, la app no presenta una regla ordinaria favorable como autorización completa para circular. Ver documentacion/BASE_NORMATIVA.md y documentacion/API.md.

La APK utiliza firma de pruebas para evaluación interna. No está preparada para publicación en tienda. La versión web requiere un servidor HTTP. Esta entrega no añade OCR ni notificaciones en segundo plano.

Archivos: APK, web compilada, recursos de la identidad actual y SHA256SUMS.txt. Código de app 1.0.1+2.
